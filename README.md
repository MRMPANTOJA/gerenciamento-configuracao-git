# Gerenciamento de Configuração de Software com Git e GitHub

## Descrição do projeto

Este repositório foi criado para demonstrar, na prática, os principais procedimentos de Gerenciamento de Configuração de Software utilizando Git e GitHub.

O gerenciamento de configuração permite identificar, registrar, controlar e acompanhar as alterações realizadas nos arquivos de um projeto durante seu desenvolvimento.

## Objetivos

- Compreender o funcionamento do controle de versões.
- Utilizar comandos básicos do Git.
- Registrar alterações por meio de commits.
- Trabalhar com branches para organizar modificações.
- Integrar um repositório local ao GitHub.
- Consultar o histórico de alterações do projeto.

## Ferramentas utilizadas

- Git: sistema de controle de versões distribuído.
- GitHub: plataforma de hospedagem e colaboração em repositórios Git.
- Linux: sistema operacional utilizado na atividade prática.
## Controle de versões com branches

As branches permitem desenvolver e organizar alterações de forma independente da versão principal do projeto.

Neste exercício, foi criada a branch `melhoria-documentacao` para demonstrar como uma modificação pode ser realizada separadamente, registrada por meio de um commit e posteriormente integrada à branch `main` utilizando o comando `git merge`.

Esse procedimento contribui para a organização, a rastreabilidade e a segurança das modificações realizadas durante o desenvolvimento de software.
